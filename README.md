# TweetLens Pakistan 🇵🇰

A web application that performs sentiment analysis on 13,000+ tweets from X (Twitter) 
to understand public opinion on three major issues in Pakistan:
- 🚨 Theft
- ⚡ Loadshedding  
- 💧 Water Shortage

## What It Does
- Collects tweets using Twitter scraping
- Cleans and preprocesses raw text data
- Applies NLP + sentiment analysis to classify public opinion
- Visualizes insights through an interactive web dashboard

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Python (NLP, Sentiment Analysis)
- **Data:** 13,000+ tweets from X

## How It Works
1. 13,000+ tweets were collected from X using scraping tools
2. Data was cleaned and preprocessed in Python
3. NLP + sentiment analysis was applied to classify tweets on:
   - Theft
   - Loadshedding
   - Water shortage
4. Results were visualized in this React dashboard

> **Note:** The original Python backend code for data processing and sentiment 
> analysis is not included in this repository. This repo contains the frontend 
> web application that visualizes the results.
